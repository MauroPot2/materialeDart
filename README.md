# Materiale di studio Dart

Raccolta di esercizi organizzati per settimane per studiare il linguaggio Dart e avvicinarsi allo sviluppo con Flutter.

## Organizzazione

- `week1exercise/`: variabili, tipi, input/output, condizioni e cicli
- `week2exercise/` - `week5exercise/`: esercizi progressivi
- `week6introduzioneFlutter/`: primi argomenti Flutter
- `test.dart`: file di prova alla radice

Ogni cartella può contenere codice ed eventuali appunti specifici. I contenuti sono esercitazioni indipendenti, non un'unica applicazione eseguibile.

## Come utilizzare il repository

Aprire la cartella della settimana, leggere le consegne e avviare i singoli programmi Dart dalla loro directory:

~~~bash
dart run percorso/del/file.dart
~~~

Il percorso effettivo dipende dall'esercizio. Per il codice Flutter occorre utilizzare una versione compatibile dell'SDK Flutter.

## Obiettivo

Documentare la progressione dai costrutti di base alle prime applicazioni. Gli esempi privilegiano chiarezza e sperimentazione; non sono librerie pensate per uso in produzione.
